# Агбина (agbina.ru): исследование конкурентов и прототип главной

Конкурентный анализ и прототип главной страницы поставщика профессиональных семян оптом (ООО «Фирма «Агбина», Королёв). Ниша: профессиональные семена цветов, деревьев, кустарников, хвойных, пальм и редких растений для питомников, садовых центров, фермерских хозяйств и озеленения. Сначала исследование, потом прототип.

**Смотреть прототип:** https://takedown-desing.github.io/agbina-prototype/

**Обоснование блоков со скриншотами конкурентов:** https://takedown-desing.github.io/agbina-prototype/rationale.html

## Пометки на блоках

Каждый блок в прототипе подписан ярлыком в левом верхнем углу:

* серый «Существующий блок»: есть на сайте сейчас, переработан;
* зелёный «Новый блок: по результатам исследования»: добавлен после разбора конкурентов, спроса и аудитов;
* серо-зелёный: существующий блок, дополненный по исследованию.

Кнопка «Скрыть пометки» в верхней панели убирает ярлыки. Мобильная версия: сузьте окно до 720 px или откройте с телефона. Условные значения (число позиций, цены, остатки, стоимость доставки, состав документов, срок ответа, отзывы, год основания) помечены оранжевым и заполняются клиентом.

## Как проводилось исследование

1. Вводные: техаудит Addu (22.07.2026) и маркетинговый CRO-аудит Addu (22.07.2026, case.addu.ru/cro/agbina.ru/).
2. Обход agbina.ru: 13 страниц (главная, каталог, карточка, промо-карточка из слайдера, «Оптовикам», «Бренды», «Компания», «Контакты», «Сроки доставки», «Прейскуранты», «Как работать с каталогом», «Новости», корзина), скриншоты после полной загрузки, разбор HTML, коды ответа старых URL, консоль браузера, PageSpeed Insights.
3. Спрос: WordKeeper (Яндекс Wordstat) по 100 фразам, регионы Россия и Москва, базовая и точная частотность; хвосты из базы Keys.so по 5 маскам; объёмы Google из Ahrefs.
4. Выдача: Keys.so check-top (ТОП-10 Яндекса, Москва, 14 запросов из базы), Ahrefs SERP overview (Google RU, 8 запросов), Keys.so organic keywords (оптовые запросы 9 конкурентов в ТОП-10), Arsenkin check-top по 67 запросам в Яндексе (Москва) и Google, commerce (коммерциализация и геозависимость), парсинг фраз Wordstat по России (`research/data/arsenkin_*.json`).
5. Метрики: Ahrefs batch analysis по 40 доменам, Keys.so domain dashboard по 23.
6. Конкуренты: 36 страниц 27 сайтов из ТОП-10 (главные и разделы «профессиональные семена цветов»), матрица 34 признаков, полные скриншоты 26 страниц и 20 фрагментов блоков.

Ограничения: сайт не подключён к доступным аккаунтам Яндекс.Вебмастера, Метрики и Search Console, счётчиков в HTML нет, данных о трафике и заявках нет. Yandex Cloud Wordstat API в день исследования отдавал ошибку 499, частотность снята через WordKeeper. Keys.so вернул ТОП только по 14 запросам из 52, agbina.ru и большинства нишевых конкурентов в базе Keys.so нет. Arsenkin отвечал 429 из-за параллельной нагрузки на аккаунт.
